# Heart Disease Prediction System ❤️

A machine learning web application that predicts the risk of heart disease using clinical data.

## Features
- Streamlit-based interactive UI
- KNN machine learning model
- One-hot encoded medical features
- Prediction confidence score
- Medical terms explanation box

## Machine Learning
- Algorithm: K-Nearest Neighbors (KNN)
- Feature Scaling: StandardScaler

## Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Streamlit

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
